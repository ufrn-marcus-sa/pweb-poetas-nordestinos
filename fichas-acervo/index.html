Fichas do acervo

O acervo é um vetor de objetos JSON. Esta feature mostra o mesmo vetor de duas maneiras — como fichas e como tabela — e deixa você escolher como as propriedades são lidas dentro da função.

A mesma função, outras propriedades

Abaixo, carregarDiv() é chamada de novo — sem mudar uma linha do código — para renderizar o vetor REGIOES, cujos objetos têm capital, poetas e nenhuma das propriedades do acervo. É o que a genericidade permite: a função não sabe o que está desenhando, só que tem um vetor de objetos e uma lista de chaves para ler.

Três formas de ler as mesmas propriedades

Os três modos do seletor acima são a mesma página com a função mudando só a linha que lê a propriedade. Nenhuma delas altera o objeto original.

Indexação — o objeto como mapa

item['nome']

Dot notation — a forma mais comum

item.nome

Com dot notation você acessa a propriedade pelo nome. Com indexação você informa a chave como uma string entre colchetes, o mesmo mecanismo de um vetor, só que o índice é um nome e não um inteiro.

Desestruturação — as propriedades viram variáveis

({ nome, estado, nascimento, morte }) => `<tr>...</tr>`

A desestruturação “arregaça” o objeto e puxa para fora só as propriedades que interessam. Se o objeto tivesse trinta propriedades e você só precisa de quatro, a expressão continua igual. E atribuir a uma das variáveis desestruturadas não muda o objeto de origem.

Técnicas: objetos JSON, propriedades, dot notation, destructuring, indexação do objeto como mapa, parâmetro default — origem: Receita 6 (Objetos JSON).

Dados locais em acervo.js; sem API nesta feature.
