Como o acervo é montado

A busca é só um filter seguido de um sort seguido de um map que devolve as linhas em HTML. Toda a montagem acontece em funções anônimas passadas como argumento — são callbacks: quem as executa é o Array, não o nosso código.

Antes e depois: a mesma feature, duas notações

A refatoração da receita trocou function por arrow function sem mudar o que a página faz. Os dois códigos estão abaixo, lado a lado.

Antes — funções declaradas e nomeadas

function gerarLinha(poeta) {
  return `<article>${poeta.nome}</article>`
}

function renderizar(lista) {
  const div = document.getElementById("listaPoetas")
  div.innerHTML = lista.map(gerarLinha).join("\n")
}

Depois — arrow functions, com callback anônima no map

const gerarLinha = poeta => `<article>${poeta.nome}</article>`

const renderizar = lista => {
  const div = document.getElementById("listaPoetas")
  div.innerHTML = lista.map(gerarLinha).join("\n")
}

Note que a segunda versão passa a função diretamente para o map, sem nome intermediário. É uma arrow function, é uma callback function e é anônima — as três coisas ao mesmo tempo.

Técnicas: arrow function, callback function, refatoração, map, filter, sort, join — origem: Receita 5 (JS — Arrow e Callback Functions).
