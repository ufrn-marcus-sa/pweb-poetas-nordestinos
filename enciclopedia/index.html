Enciclopédia de poetas

Tudo o que o acervo local não alcança: a Wikipédia. Cada consulta vai à API e volta com verbetes, fotos e um resumo de cada poeta.

A Wikipédia faz busca difusa: consultar um poeta que não tem verbete próprio devolve mesmo assim resultados parecidos. Para ver o que a API responde quando não acha nada, use a última opção do seletor.

A mesma função, duas origens

As duas tabelas abaixo foram montadas pela mesma função montarTabela(), importada do arquivo ../tabela.js. Ela não sabe de onde vieram os objetos, nem o que eles significam: recebe um vetor, uma lista de colunas e o id de um elemento, e desenha.

Do que a resposta precisa virar

A API devolve a busca já pronta, mas dentro de um objeto indexado pelo id de cada página, não num vetor. Isso acontece porque a Wikipédia pode devolver um verbete que não existe mais, e o lugar vazio fica reservado. 

resposta.query.pages  //  { "1278824": {...}, "3478499": {...} }

Object.values(resposta.query.pages)  //  [ {...}, {...} ]

Só depois disso o vetor tem a forma que o map da receita espera. É uma linha a mais que o enunciado mostra, mas é o que a API real devolve.

Técnicas: fetch, await, async, try/catch, response.json(), renderizador genérico em arquivo .js separado — origem: Receita 7 (Fetch).

Fonte dos verbetes: Wikipédia em português, via API MediaWiki. As imagens pertencem à Wikimedia Commons.
